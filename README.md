# Alpha Bot 🛡️

منظومة وساطة وضمان مالي لتداول العملات الرقمية شخص لشخص (P2P) عبر تيليغرام، تتيح تبادل USDT (شبكة BNB Smart Chain - BEP20) مقابل الليرة السورية (SYP) عبر وسائل الدفع المحلية المعتمدة (شام كاش، سيريتل كاش، وغيرها) بآلية حجز الضمان وإدارة النزاعات.

---

## متطلبات التشغيل الأساسية

- **Python**: الإصدار 3.10 أو أحدث (يُفضل 3.11).
- **PostgreSQL**: الإصدار 14 أو أحدث (محلياً أو سحابياً).
- **حساب بوت تيليغرام**: استخراج `BOT_TOKEN` من [@BotFather](https://t.me/BotFather).

---

## خطوات التثبيت والتشغيل المحلي

### 1. تجهيز البيئة الافتراضية وتثبيت الاعتماديات

```bash
# إنشاء وتفعيل البيئة الافتراضية
python3 -m venv venv
source venv/bin/activate  # على ويندوز: venv\Scripts\activate

# تثبيت الحزم المطلوبة
pip install --upgrade pip
pip install -r requirements.txt
```

### 2. إعداد قاعدة البيانات

قم بإنشاء قاعدة بيانات جديدة على PostgreSQL:
```sql
CREATE DATABASE alpha_p2p_db;
```

### 3. ضبط ملف المتغيرات البيئية (`.env`)

انسخ النموذج `.env.example` إلى `.env` واملأ المتغيرات:
```bash
cp .env.example .env
```

| المتغير | الوصف | إلزامي / اختياري |
|---|---|---|
| `BOT_TOKEN` | رمز التوثيق الخاص بالبوت من BotFather | إلزامي |
| `DATABASE_URL` | رابط اتصال قاعدة البيانات (`postgresql+asyncpg://user:pass@host:5432/dbname`) | إلزامي |
| `ADMIN_IDS` | معرّف أو معرّفات المدراء في تيليغرام مفصولة بفواصل (مثل `123456789`) | إلزامي |
| `BOT_USERNAME` | اسم مستخدم البوت الفعلي على تيليغرام بدون علامة `@` | إلزامي |
| `CHANNEL_ID` | معرّف قناة النشر العامة (يبدأ عادة بـ `-100`) لنشر عروض Alpha P2P | إلزامي في حال تفعيل النشر |
| `CHANNEL_USERNAME` | اسم مستخدم قناة النشر بدون علامة `@` (لروابط القناة) | اختياري |
| `SUPPORT_USERNAME` | اسم مستخدم حساب الدعم الفني على تيليغرام بدون علامة `@` | اختياري |

### 4. تطبيق ترقيات قاعدة البيانات (Alembic)

```bash
# تطبيق أحدث ترقيات قاعدة البيانات
alembic upgrade head

# التحقق من حالة الهجرة الحالية
alembic current
```

### 5. تشغيل البوت

```bash
python -m bot.main
```

> **ملاحظة:** يقوم النظام آلياً عند الإقلاع الأول بإنشاء وتحديث بنية الجداول والفهارس في قاعدة البيانات.

## بنية المشروع

```text
├── bot/
│   ├── handlers/       # معالجات الأوامر والرسائل (base, offers, deals, profile, admin, ...)
│   ├── middlewares/    # طبقات التحقق (الصيانة، معدل الطلبات، إلغاء الحالات)
│   ├── services/       # الخدمات المساندة (النشر في القناة، التدقيق)
│   ├── states/         # آلات الحالات (FSM)
│   └── utils/          # الأدوات المساعدة، التحقق من العناوين، والهوية
├── config/             # إعدادات التطبيق وقراءة البيئة
├── db/                 # نماذج البيانات وإدارة الاتصال بقاعدة البيانات
├── tests/              # اختبارات التحقق من صحة العناوين والهوية
└── requirements.txt    # قائمة المكتبات والاعتماديات
```
